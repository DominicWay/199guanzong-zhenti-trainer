# 199 管综真题答题卡训练系统

> 单文件、纯前端、离线可用的管综真题答题卡 + 计时训练工具。选好年份和模块就能模拟作答，交卷自动出 xlsx 用时与准确率报告。

**在线使用**：开启 GitHub Pages 后访问 `https://<你的GitHub用户名>.github.io/199guanzong-zhenti-trainer/`（浏览器直接打开，无需安装）

## 这是什么

备考 199 管理类综合能力联考（MBA/MPA/MPAcc 等）时，光会做题不够，还得**控制时间**。本工具把 2010—2026 年共 17 套真题的参考答案内置进来，提供一个模拟答题卡：

- 只做答题卡与计时（不含题目内容，题目请用纸质真题或 PDF）
- 每题记录**思考用时**（可断续多段），交卷自动生成 Excel 报告
- 目标：练出「单题止损」和「板块硬截止」的考场节奏

## 功能

### 选题
- 年份单选：2010—2026 共 17 套真题
- 模块多选：【问题求解】【条件充分性判断】【逻辑推理】
  - 约束：【问题求解】与【条件充分性判断】必须同时选、同时退
- 时间目标自动叠加显示：
  - 数学（问题求解 + 条件充分性判断）：优秀 55 min / 上限 60 min
  - 逻辑推理：优秀 50 min / 上限 60 min
  - 全卷：优秀 105 min / 上限 120 min

### 答题
- 每题 A—E 五个选项，点选即记录（再点同一选项可停掉本题计时）
- **跳过 / 继续**：每题独立计时，同一时刻只有一题在计时
  - 「跳过」：本题思考暂停，下一题开始计时
  - 「继续」：回到该题接着计时（此前别的题自动暂停）
  - 选出答案即本题计时停止；点「继续」可再研究（记为「研究」段），再点答案再停
- **标注按钮**（与选项独立，仅作标记，便于后期分析）：
  - `猜的`：不会/没时间，纯瞎蒙
  - `凭推理`：有点依据但没把握
  - `凭感觉`：凭感觉选的
  - 三选一，再点同一标注取消，点另一标注可更换
- **全局暂停**：所有题一起冻结（休息、接电话等）
- 顶栏实时显示总思考用时、进度、当前思考中的题

### 报告（交卷自动导出 xlsx）
三个工作表：

| 表 | 内容 |
|---|---|
| 概览 | 套题与模块、时间目标达成判定、得分情况（正确率、标注分计数）、用时口径说明 |
| 答题对比 | 逐题：我的答案 / 标注 / 参考答案 / 判定 / 分值 / 得分 / 本题用时 / 思考段数 |
| 用时明细 | 思考段流水（每段时长）+ 按题汇总（含跳过次数）+ 总思考用时 + 模块用时小计 |

**用时口径**：
- 本题用时 = 该题各思考段之和（断续多段累加）
- 总思考用时 = 全部题思考用时之和（同一时刻只有一题在计时，故与卷面实际用时一致）
- 全局「暂停」的时间不计入

**导出位置**：Chrome/Edge 下首次交卷会弹出文件夹选择框，选一次目标文件夹后**直写**（记住选择，下次不用再选）；其他浏览器自动降级为下载 xlsx。

## 本地使用

不想在线用也行，下载 `index.html` 双击打开即可（推荐 Chrome/Edge）：

1. 打开 `index.html`
2. 选年份、勾模块 → 开始答题
3. 对照纸质真题/PDF 作答，每题点 A—E，不会的点「跳过」
4. 做完点「交卷」→ 自动导出 xlsx 报告

数据保存在浏览器 localStorage：未交卷时关掉页面，下次打开会提示恢复练习（离线时间按暂停处理，不会误计时）。

## 技术说明

- **单文件**：HTML + CSS + vanilla JS 全在一个文件里，无构建、无依赖、无后端
- **内嵌最小 XLSX 生成器**：ZIP STORE + CRC32 + 手写 OOXML，离线也能出 Excel 报告
- **File System Access API**：报告直写指定文件夹（Chrome/Edge 86+）；不支持时降级为下载
- **localStorage**：会话与设置持久化

## 常见问题

**Q：有题目内容吗？**
没有。本工具只做答题卡和计时，题目请使用纸质真题或 PDF。

**Q：答案数据准确吗？**
内置 2010—2026 年真题选择题参考答案（问题求解 15 题 + 条件充分性判断 10 题 + 逻辑推理 30 题）。如有发现错误，欢迎提 Issue。

**Q：换浏览器/换电脑数据还在吗？**
localStorage 按浏览器 + 域名隔离，不跨浏览器、不跨设备同步。报告文件本身是 xlsx，不受影响。

**Q：能改时间目标吗？**
目前时间目标固定为考试实战推荐值（数学 55/60、逻辑 50/60、全卷 105/120 分钟）。有自定义需求欢迎提 Issue。
